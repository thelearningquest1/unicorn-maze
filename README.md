# 🦄 Unicorn Rainbow Maze Adventure

A magical maze game for kids, featuring 10 progressively challenging levels!

## 🌈 Features

- **10 unique mazes** that get harder as you improve
- **Unicorn & rainbow theme** with beautiful animated graphics
- **Skill badges** to earn as you develop abilities
- **Star rating system** (1–3 stars per level based on speed & hints)
- **XP progression bar** to track your growth
- **Hint system** for when you get stuck
- **D-Pad controls** for mobile + keyboard arrows for desktop
- **Swipe controls** on touchscreens

## 🎮 How to Play

1. Help Sparkle the Unicorn 🦄 reach the Rainbow 🌈
2. Use **arrow keys** (keyboard) or the **D-Pad buttons** (mobile)
3. You can also **swipe** on the maze itself!
4. Earn up to **3 stars** per level
5. Collect **skill badges** for special achievements

## 🏅 Skill Badges

| Badge | How to Earn |
|-------|-------------|
| 👣 First Steps | Complete your first maze |
| ⚡ Speed Racer | Finish a maze in under 30 seconds |
| 💎 Perfect Run | Complete a maze without hints |
| 🌟 Halfway Hero | Complete 5 mazes |
| 🎯 Laser Focus | Finish without resetting |
| 🌈 Rainbow Star | Earn 3 stars on any maze |
| 🏆 Champion | Complete all 10 mazes |
| 🦄 Unicorn Lord | Earn 25+ total stars |

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository named `unicorn-maze`
2. Upload `index.html` to the repository
3. Go to **Settings → Pages**
4. Set source to **main branch / root folder**
5. Your game will be live at `https://YOUR-USERNAME.github.io/unicorn-maze/`
